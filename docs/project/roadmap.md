# Roadmap

Direction for the next 12 months. Not commitments or dates.

## Intend to do

- Broaden connector coverage across the supported clouds and platforms.
- Improve verification quality and reduce false findings.
- Expand evaluation datasets.
- Add agent memory across sessions.
- Add MCP support.
- Ship a GitHub Action for pull-request checks.

## Do not intend to do

- No hosted SaaS. Cynative runs in your environment.
- No write-by-default mode. Read-only stays the default.
- No telemetry or phone-home.
- No model lock-in. BYOM stays supported even once we ship our own
  specialized model.

Direction changes are discussed in
[GitHub Discussions](https://github.com/cynative/cynative/discussions).
