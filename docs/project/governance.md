# Governance

Cynative is maintained by Cynative Ltd.

## Roles

- **Maintainers** (Yuri, Shaked): review and merge PRs, triage issues,
  cut releases, respond to security reports per SECURITY.md.
- **Contributors**: anyone opening an issue or PR. See CONTRIBUTING.md.

## Decisions

Maintainers decide by consensus. Roadmap direction is set by the maintainers.

## Continuity

Both maintainers hold full admin. Either can independently triage issues,
merge PRs and publish a release, so the project continues without
interruption if one becomes unavailable.
