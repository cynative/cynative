# Governance

Cynative is maintained by Cynative Ltd.

## Roles

- **Maintainers** ([@0xh0b0](https://github.com/0xh0b0),
  [@ShakedZ](https://github.com/ShakedZ)): review and merge PRs, triage
  issues, cut releases, respond to security reports per
  [SECURITY.md](../../SECURITY.md).
- **Contributors**: anyone opening an issue or PR. See
  [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Continuity

Both maintainers hold full admin across the repository and release infrastructure. Either can independently triage issues, merge PRs and publish a release, so the project continues without interruption if one
becomes unavailable.
